# Contributing

You will need a Text Editor - Windows Notepad does not count, git - our source control solution, and hemtt - our build solution. Please ask if you need help setting these up. Some suggested extensions are included for VSCode.

Once you have cloned this repository you can build the mod by running `hemtt build` or launch into Arma 3 with `hemtt launch`.

Once you have made your changes commit these to a branch other than main, and create a pull request. This will be reviewed before it is merged into the mod.
